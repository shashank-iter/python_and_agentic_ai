# AsyncIO or Asynchronous Programming python

- async creates a coroutine, bascially a special function which can run is a non blocking manner
- await keyword specifies to wait in a non blocking manner
- event loop: similar to JS event loop, its the engine that runs and schedules the co-routines in python.
- Blocking vs Non Blocking: time.sleep() is a blocking operation and asyncio.sleep() is non blocking
- Daemon and Non Daemon Threads
- Daemon threads are those threads which automatically shutdown when main thread is gone
- Vice Versa for non daemon threads
- profiling in python
- pyspy and vprof
- thread scope also.
